# Mamuna_Graphics_Library
A C library based on OpenGL and GLFW, cglm, etc.
Inspired by SDL. Designed to make it easier to have full control over OpenGL.
This library has the same limitations as OpenGL and you,
because you create the shaders yourself and manage the entire pipeline.
